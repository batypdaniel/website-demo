Technical details
  • Text recognition: {{ inv.config.ocr }}
  • Language model: {{ inv.config.llm }}
  • Fields extracted: {% for f in inv.fields %}{{ f.label }}{% if not loop.last %}, {% endif %}{% endfor %}, plus every line item
  • Review threshold: {{ inv.config.review_threshold }} - any value below it, a missing required field or a failed check sends the invoice to a person instead of straight into the books
  • Checks: line items add up to the subtotal, quantity × unit price = amount on every line, and subtotal + tax + shipping = total
